A new version of Diablo, created by former Bethesda developers, finally enhances the 1997 classic with stunning HD graphics

Two Bethesda veterans have independently developed a remake of the first Diablo. The project completely revamps the graphics and adds ray tracing, as well as modernizing the gameplay.

Adrian Werner

October 13, 2026 02:00

Listen to audio version of this article
Sponsored by
0:00 / 1:43
Instaread

Two former Bethesda employees decided to take matters into their own hands and give the first Diablo a fresh look. The result is the DamnationX mod, which can easily be described as an unofficial remake.

The project is based on an older mod, DevilutionX, which modernized Blizzard’s classic action RPG by introducing, among other things, support for high-resolution widescreen displays. DamnationX, however, goes much further in terms of revamping the game.

  1. DamnationX thoroughly enhances the graphics, replacing the old visual elements with new, high-resolution ones, which covers both characters and the enviorements. Ray tracing support has also been added.
  2. The upgrades are especially noticeable in the characters, which have received completely new models with custom animations. Not everything works as it should yet, since the mod is still in beta version 4. Some animations look wonky (especially the way the warrior walks), but these elements are set to be improved in the future.
  3. Notable changes have also been made to the gameplay. A stamina bar and a sprint option have been added. Interestingly, when you’re racing across the maps, enemies will also speed up to keep up with you, which drastically changes the gameplay.
  4. A new online lobby has also been introduced. The mod allows up to four players to play online.

DamnationX is, in practice, a completely new game. However, for obvious legal reasons, the developers couldn’t release it as a standalone title. That’s why you’ll need the original Diablo to play it—specifically, one file from that game: DIABDAT.MPQ.

You can download the DamnationX mod as files to run locally, or use the browser-based version at www.damnationx.net.
